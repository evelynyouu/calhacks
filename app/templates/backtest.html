How this works

Four separate simulated portfolios start with the same amount on {{ bt.summary.start }} and receive the same bi-weekly paycheck deposits. New money always goes to the most underweight holding first. The auto-trade strategy additionally rebalances drift every {{ bt.summary.review_every_days }} days, selling overweight holdings and buying underweight ones. The other strategies never rebalance. Returns are money-weighted (your actual dollars in vs out).

This is a simulation using the same price model the rest of the app uses. Past simulated performance doesn't predict future results.
